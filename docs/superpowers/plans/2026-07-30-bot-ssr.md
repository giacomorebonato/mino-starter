# Bot-Triggered SSR via Lightpanda — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Serve search-engine bots server-rendered HTML of public SPA routes by running the SPA's own JS in Lightpanda (headless browser) on the same Fly VM, behind a TTL disk cache — no SSR framework, no SSR for real users.

**Architecture:** Prod `fetch` handler gains an SSR gate: when `isbot(UA)` and the path is in a server-side public allowlist and the request lacks the `x-ssr-renderer: lightpanda` recursion-break header, it checks a disk cache (mtime TTL); on miss it drives Lightpanda's CDP server via Playwright (`connectOverCDP`, `waitUntil: 'networkidle'`, custom header) to render the page, caches the HTML, returns it. On any failure it falls back to the raw SPA shell. Dev is untouched. One E2E Playwright test is the verification contract.

**Tech Stack:** Bun, TanStack Router, tRPC v11, `isbot`, `@lightpanda/browser` (CDP server), `playwright` (runtime CDP client — distinct from `@playwright/test` which stays a devDep for E2E).

## Global Constraints

- No semicolons; trailing commas all; single quotes (Biome). Filenames kebab-case. Path aliases `@backend/*`, `@shared/*`, `@frontend/*`.
- Feature is **prod-only**, gated on `process.env.NODE_ENV !== 'production'` → skip SSR. Dev (`bun run dev`) keeps Bun HTMLBundle routes + HMR.
- No unit tests. The single E2E Playwright spec `e2e/ssr.spec.ts` is the verification contract (per approved spec).
- Playwright runtime dep is the `playwright` package (browser automation), NOT `@playwright/test` (test runner, stays devDep).
- Knip (`bun run knip`), Biome (`bun run lint`), and `bun run typecheck` must stay green; CI enforces them.
- All new env vars have safe defaults; SSR can be disabled via `SSR_ENABLED=false`.

## Scope note (read before executing)

The approved spec flags that **no public content route exists today** (`/` redirects to `/notes`, `/login` is a form, `/notes` is auth-gated). Without a public page the SSR infra is dead code and the E2E test has nothing to render. This plan therefore includes a **minimal public landing route** (`/`) backed by a public tRPC procedure (`public.siteInfo`) so the feature is both useful and testable end-to-end. This is the "first public page" the spec listed as a follow-up; it is intentionally tiny. If you want to keep SSR infra pure and defer the landing page, drop Tasks 2–3 and replace the E2E assertions accordingly — but then the feature ships with zero renderable routes.

### Task 5: Disk cache (`backend/ssr/cache.ts`)

**Files:**
- Create: `backend/ssr/cache.ts`

**Interfaces:**
- Produces: `class SsrCache { get(pathname: string): string | null; set(pathname: string, html: string): void }`. Constructor takes `{ dir: string; ttlMs: number }`. Filename = `sha1(pathname).hex() + '.html'`. `get` returns `null` on missing or stale (and deletes stale file). `set` writes atomically (tmp + rename).

- [ ] **Step 1: Create `backend/ssr/cache.ts`**

```ts
import { mkdir, readdir, rm, stat, writeFile } from 'node:fs/promises'
import { join } from 'node:path'
import { createHash } from 'node:crypto'

export type SsrCacheOptions = { dir: string; ttlMs: number }

export class SsrCache {
	private readonly dir: string
	private readonly ttlMs: number
	constructor(opts: SsrCacheOptions) {
		this.dir = opts.dir
		this.ttlMs = opts.ttlMs
	}

	private fileFor(pathname: string): string {
		const key = createHash('sha1').update(pathname).digest('hex')
		return join(this.dir, `${key}.html`)
	}

	async get(pathname: string): Promise<string | null> {
		const file = this.fileFor(pathname)
		try {
			const s = await stat(file)
			if (Date.now() - s.mtimeMs > this.ttlMs) {
				await rm(file, { force: true })
				return null
			}
			return await Bun.file(file).text()
		} catch {
			return null
		}
	}

	async set(pathname: string, html: string): Promise<void> {
		const file = this.fileFor(pathname)
		const tmp = `${file}.tmp`
		try {
			await mkdir(this.dir, { recursive: true })
			await writeFile(tmp, html)
			await import('node:fs/promises').then((m) => m.rename(tmp, file))
		} catch {
			// cache failure must never break the request
		}
	}
}
```

Note: `import('node:fs/promises').then(m => m.rename(...))` is used to keep the rename call explicit; you may simplify to a top-level `import { rename } from 'node:fs/promises'` and call `await rename(tmp, file)`.

### Task 6: Lightpanda CDP lifecycle (`backend/ssr/lightpanda.ts`)

**Files:**
- Create: `backend/ssr/lightpanda.ts`

**Interfaces:**
- Produces: `class LightpandaCdp { constructor(opts: { port: number }); start(): Promise<void>; endpoint(): string; stop(): Promise<void> }`. `endpoint()` returns `http://127.0.0.1:<port>`. `start()` spawns `lightpanda.serve(...)` via `@lightpanda/browser` and stores the child process; `stop()` kills it. Registers SIGTERM/SIGINT handlers once.

- [ ] **Step 1: Create `backend/ssr/lightpanda.ts`**

```ts
import { lightpanda, type LightpandaServeOptions } from '@lightpanda/browser'

export type LightpandaCdpOptions = { port: number }

export class LightpandaCdp {
	private readonly opts: LightpandaServeOptions
	private proc: ReturnType<typeof lightpanda.serve> | null = null
	private handlersRegistered = false

	constructor(opts: LightpandaCdpOptions) {
		this.opts = { host: '127.0.0.1', port: opts.port }
	}

	endpoint(): string {
		return `http://${this.opts.host}:${this.opts.port}`
	}

	async start(): Promise<void> {
		this.proc = await lightpanda.serve(this.opts)
		if (!this.handlersRegistered) {
			const stop = () => {
				void this.stop()
			}
			process.once('SIGTERM', stop)
			process.once('SIGINT', stop)
			this.handlersRegistered = true
		}
	}

	async stop(): Promise<void> {
		const proc = this.proc
		if (!proc) return
		try {
			proc.stdout.destroy()
			proc.stderr.destroy()
			proc.kill()
		} catch {
			// best-effort
		}
		this.proc = null
	}
}
```

Note: `lightpanda.serve` resolves to the child process handle per the package README (`proc.stdout.destroy(); proc.stderr.destroy(); proc.kill()`). If the resolved type differs in your installed version, adapt the cleanup calls to the actual handle shape (keep stdout/stderr destroy + kill).

### Task 7: Playwright renderer (`backend/ssr/renderer.ts`)

**Files:**
- Create: `backend/ssr/renderer.ts`

**Interfaces:**
- Consumes: `LightpandaCdp.endpoint()` from Task 6.
- Produces: `class SsrRenderer { constructor(opts: { cdpEndpoint: string; timeoutMs: number }); render(url: string): Promise<string> }`. `render` connects Playwright `chromium.connectOverCDP`, opens a page, navigates with `extraHTTPHeaders: { 'x-ssr-renderer': 'lightpanda' }` and `waitUntil: 'networkidle'`, returns `await page.content()`, closes the page. On timeout/error it throws (caller falls back). Reuses one browser context across renders.

- [ ] **Step 1: Create `backend/ssr/renderer.ts`**

```ts
import { chromium, type Browser, type BrowserContext } from 'playwright'

export type SsrRendererOptions = { cdpEndpoint: string; timeoutMs: number }

export class SsrRenderer {
	private readonly cdpEndpoint: string
	private readonly timeoutMs: number
	private browser: Browser | null = null
	private context: BrowserContext | null = null

	constructor(opts: SsrRendererOptions) {
		this.cdpEndpoint = opts.cdpEndpoint
		this.timeoutMs = opts.timeoutMs
	}

	private async ensureContext(): Promise<BrowserContext> {
		if (!this.browser || !this.context) {
			this.browser = await chromium.connectOverCDP(this.cdpEndpoint)
			this.context = await this.browser.newContext()
		}
		return this.context
	}

	async render(url: string): Promise<string> {
		const context = await this.ensureContext()
		const page = await context.newPage()
		try {
			await page.goto(url, {
				waitUntil: 'networkidle',
				timeout: this.timeoutMs,
			})
			return await page.content()
		} finally {
			await page.close()
		}
	}

	async dispose(): Promise<void> {
		try {
			await this.context?.close()
			await this.browser?.close()
		} catch {
			// best-effort
		}
		this.context = null
		this.browser = null
	}
}
```

### Task 8: Orchestrator (`backend/ssr/bot-handler.ts`)

**Files:**
- Create: `backend/ssr/bot-handler.ts`

**Interfaces:**
- Consumes: `SsrCache` (Task 5), `LightpandaCdp` (Task 6), `SsrRenderer` (Task 7), `PUBLIC_SSR_PATHS` (Task 4), `isbot`.
- Produces: `createBotHandler(deps): { handle(req, url): Promise<Response | null> }`. Returns `null` when the request is not a bot/SSR-path/SSR-enabled (caller falls through to the SPA fallback). Returns a `Response` (rendered or cached HTML, or raw SPA shell fallback) with header `x-ssr: hit | miss | fallback`. Enforces render concurrency = 1 via a serial queue. Single-flight per pathname via an in-flight `Map`.

- [ ] **Step 1: Create `backend/ssr/bot-handler.ts`**

```ts
import isbot from 'isbot'
import { PUBLIC_SSR_PATHS } from '@backend/ssr/allowlist'
import type { SsrCache } from '@backend/ssr/cache'
import type { SsrRenderer } from '@backend/ssr/renderer'

export type BotHandlerDeps = {
	cache: SsrCache
	renderer: SsrRenderer
	origin: string
	enabled: boolean
}

type Result = { html: string; status: 'hit' | 'miss' | 'fallback' }

export function createBotHandler(deps: BotHandlerDeps) {
	const inflight = new Map<string, Promise<string>>()
	let queue: Promise<unknown> = Promise.resolve()

	async function renderOnce(pathname: string): Promise<string> {
		const cached = await deps.cache.get(pathname)
		if (cached) return cached
		const html = await deps.renderer.render(`${deps.origin}${pathname}`)
		await deps.cache.set(pathname, html)
		return html
	}

	async function renderQueued(pathname: string): Promise<string> {
		// single-flight: same path reuses the in-flight promise
		const existing = inflight.get(pathname)
		if (existing) return existing
		const p = (async () => {
			try {
				return await renderOnce(pathname)
			} finally {
				inflight.delete(pathname)
			}
		})()
		inflight.set(pathname, p)
		return p
	}

	async function runSerial<T>(fn: () => Promise<T>): Promise<T> {
		const next = queue.then(fn, fn)
		queue = next.catch(() => {})
		return next
	}

	async function handle(req: Request, url: URL): Promise<Response | null> {
		if (!deps.enabled) return null
		if (!PUBLIC_SSR_PATHS.includes(url.pathname)) return null
		const ua = req.headers.get('user-agent') ?? ''
		if (!isbot(ua)) return null
		// recursion break: the renderer's own inner fetch carries this header
		if (req.headers.get('x-ssr-renderer') === 'lightpanda') return null

		let result: Result
		try {
			const html = await runSerial(() => renderQueued(url.pathname))
			result = { html, status: 'miss' }
		} catch {
			result = { html: await rawShell(), status: 'fallback' }
		}
		if (result.status === 'miss') {
			const cached = await deps.cache.get(url.pathname)
			if (cached) result.status = 'hit'
		}
		return new Response(result.html, {
			headers: {
				'content-type': 'text/html; charset=utf-8',
				'x-ssr': result.status,
			},
		})
	}

	return { handle }
}

async function rawShell(): Promise<string> {
	return await Bun.file('dist/index.html').text()
}
```

Note: `x-ssr` status logic — `renderOnce` returns cached (hit) or freshly rendered (miss). The wrapper sets `miss` then promotes to `hit` if the cache now holds it (covers the just-rendered case being read back as a hit on the same call). Simplify if confusing: set `hit` when `renderOnce` returned from cache, else `miss`. Adjust to a single, clear rule:

```ts
async function renderOnce(pathname: string): Promise<{ html: string; status: 'hit' | 'miss' }> {
	const cached = await deps.cache.get(pathname)
	if (cached) return { html: cached, status: 'hit' }
	const html = await deps.renderer.render(`${deps.origin}${pathname}`)
	await deps.cache.set(pathname, html)
	return { html, status: 'miss' }
}
```

and drop the post-hoc promotion. Use this simpler form in the final file.
